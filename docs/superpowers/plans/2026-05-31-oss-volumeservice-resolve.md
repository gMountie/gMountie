# VolumeService.Resolve (referral) — Server Side — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `VolumeService.Resolve(volume) → {location}` RPC. The OSS server
returns an empty `location` meaning "I serve this volume here" (after checking
the principal may access it). This is the additive protocol seam that lets a
federating/HA server — or the gMountie-cloud resolver — refer a client to a
different data host; the OSS implementation is the trivial "local" case.

**Architecture:** Three thin layers, matching the existing `List` flow.
`api/proto/volume.proto` gains the RPC + messages. The service
(`pkg/server/service/volume.go`) gains `Resolve(ctx, volume) (string, error)`
that runs the existing `PrincipalCanAccess` ACL check + an existence check and
returns `""` (local). The gRPC controller
(`pkg/server/controller/volume.go`) gains a `Resolve` handler that delegates and
wraps the location in the reply — mirroring `List`.

**Tech Stack:** Go, gRPC + protoc (`task gen:grpc`), testify suites
(`github.com/stretchr/testify/suite`), `google.golang.org/grpc/status` +
`codes`. Module path is `go.gmountie.dev/gmountie` (post-rename).

**Scope note:** This is the **server half**. The **client "follow a referral"**
change (resolve → reconnect before mounting) is a separate, more-involved PR
(it touches the mount/dial flow in `pkg/client/mount` + `pkg/client/grpc`) and
gets its own plan.

- [ ] **Step 1: Write the failing test**

Create `pkg/server/service/resolve_test.go`. It reuses the helpers already in

```go
package service

import (
	"context"
	"testing"

	"go.gmountie.dev/gmountie/pkg/server/config"

	"github.com/stretchr/testify/suite"
	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/status"
)

type ResolveSuite struct{ suite.Suite }

func TestResolveSuite(t *testing.T) { suite.Run(t, new(ResolveSuite)) }

// With default_allow (nil → true) and no per-user restriction, any principal
// resolves an existing volume to the local ("") location.
func (s *ResolveSuite) TestResolve_LocalForAccessibleVolume() {
	svc := s.buildService(authWithUsers(nil))
	loc, err := svc.Resolve(ctxFor("alice"), "photos")
	s.Require().NoError(err)
	s.Equal("", loc) // empty = served here
}

// A principal restricted away from the volume is denied (ACL runs first, so
// existence is not leaked).
func (s *ResolveSuite) TestResolve_DeniedPrincipal() {
	// bob may access only "team"; default_allow=false.
	svc := s.buildService(authWithUsers(boolPtr(false),
		config.BasicAuthConfigUser{Username: "bob", Volumes: []string{"team"}},
	))
	_, err := svc.Resolve(ctxFor("bob"), "photos")
	s.Require().Error(err)
	s.Equal(codes.PermissionDenied, status.Code(err))
}

// An allowed principal asking for a volume that does not exist gets NotFound.
func (s *ResolveSuite) TestResolve_UnknownVolume() {
	svc := s.buildService(authWithUsers(nil))
	_, err := svc.Resolve(ctxFor("alice"), "does-not-exist")
	s.Require().Error(err)
	s.Equal(codes.NotFound, status.Code(err))
}

// No authenticated principal is denied (mirrors PrincipalCanAccess).
func (s *ResolveSuite) TestResolve_NoPrincipal_Denied() {
	svc := s.buildService(authWithUsers(boolPtr(false)))
	_, err := svc.Resolve(context.Background(), "photos")
	s.Require().Error(err)
	s.Equal(codes.PermissionDenied, status.Code(err))
}
```

Add this method to `pkg/server/service/volume.go` (it uses the existing

imported in this file):

```go
// Resolve checks access then reports where the volume lives. The OSS server
// always serves its configured volumes locally, so it returns "" on success.
func (s *VolumeServiceImpl) Resolve(ctx context.Context, volume string) (string, error) {
	// ACL first — do not leak existence to an unauthorized principal.
	if err := s.PrincipalCanAccess(ctx, volume); err != nil {
		return "", err
	}
	if _, ok := s.volumes[volume]; !ok {
		return "", status.Errorf(codes.NotFound, "volume %q not found", volume)
	}
	return "", nil
}
```

	"go.gmountie.dev/gmountie/pkg/proto"

func (s *ResolveCtrlSuite) newController() *VolumeServiceImpl {
	cfg := &config.Config{
		Volumes: []*config.VolumeConfig{

				Path:    s.T().TempDir(),

- [ ] **Step 3: Add the controller handler**

```go
// Resolve reports where a volume is served. Delegates to the service, which
// runs the ACL check; the OSS server returns an empty location (served here).
func (v *VolumeServiceImpl) Resolve(ctx context.Context, req *proto.VolumeResolveRequest) (*proto.VolumeResolveReply, error) {
	location, err := v.service.Resolve(ctx, req.GetName())
	if err != nil {
		return nil, err
	}
	return &proto.VolumeResolveReply{Location: location}, nil
}
```
